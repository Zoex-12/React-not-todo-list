# 📝 Not Todo List

A productivity web app that helps you **track tasks you should avoid** and focus on what actually matters. Add tasks with estimated hours, move them to the avoidable list, and keep track of your time better.

## ✨ Features

- ➕ Add tasks with estimated hours
- 🗑️ Move tasks to the avoidable list
- ⏱️ Track total hours spent on tasks
- 📱 Fully responsive design for all screen sizes
- ⚡ Fast and lightweight with Vite

---

## 🛠️ Tech Stack

- **React** — UI components and state management
- **Tailwind CSS** — Styling and responsive design
- **Vite** — Build tool and development server
- **JavaScript (ES6+)** — Core logic and functionality

---

## 📦 Installation & Setup

1. **Clone the repository**

```bash
git clone https://github.com/Zoex-12/not-todo-list.git
```

2. **Navigate to the project folder**

```bash
cd not-todo-list
```

3. **Install dependencies**

```bash
npm install
```

4. **Start the development server**

```bash
npm run dev
```

5. **Open your browser and go to**

```
http://localhost:5173
```

---

## 📖 Usage

1. Enter a task name and estimated hours in the form
2. Click **"Add New Task"** to add it to the task list
3. Click the 🗑️ button to move a task to the **Avoidable Task** list
4. Track your total hours at the bottom
